## Getting started

You can preview the notebooks directly on GitHub, or run them locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/machine-learning.git
   cd machine-learning
   ```

2. (Recommended) Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install the notebook and data-analysis tools:

   ```bash
   python -m pip install jupyter numpy pandas matplotlib
   ```

4. Start Jupyter:

   ```bash
   jupyter notebook
   ```

Open any `.ipynb` file from its topic folder. You can also upload notebooks to [Google Colab](https://colab.research.google.com/) to run them in your browser.
